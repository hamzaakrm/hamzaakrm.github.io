03 · Projects

Things I've built

PR Sentinel

↗
Latest · Published on GitHub Marketplace

An AI code reviewer for GitHub pull requests. Every time a pull request is opened, it runs static analysis (ruff and bandit) to catch security issues such as SQL injection, shell injection and hard coded secrets, then asks an LLM to look for logic bugs that linters miss, and posts the results as inline comments with suggested fixes. Gemini, Claude, OpenAI or a local Ollama model plug in behind one interface. Every AI comment's line number is checked against the diff before posting, and when the AI service is busy it retries and falls back to a lighter model. In a test pull request with five planted logic bugs, it caught all five.

Verity

↗

A personal AI assistant that remembers you and checks what it tells you. I built it by merging Aura and TruthLens into one application, then took it further. It routes each message to either local chat or a research pipeline, answers with citations and a confidence label counted from genuinely independent sources, and keeps follow up questions on the sources it already fetched. It also verifies images, holds a voice conversation, and runs on your own machine with an optional cloud model behind a single toggle.
